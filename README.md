# Prompt Atelier

三位**独立选择**的 Prompt 优化师。这个网页负责把你的输入与所选角色的指令组合成可复制的 Prompt；它**不调用 AI 模型，也不在网页内完成优化或评分**。

## 使用

1. 双击 `index.html`，在浏览器中打开。无需安装依赖或启动服务。
2. 只选择一位优化师：
   - **结构化生成师**：从需求或想法出发，让外部 AI 写出结构化 Prompt。
   - **Prompt 评估师**：针对已有 Prompt，请外部 AI 做文本质量诊断、评分并给出修改版。评分是模型的主观判断，不代表实测效果。
   - **CRISPE 调优师**：针对已有 Prompt，让外部 AI 参考 CRISPE 框架重构并给出示例。
3. 输入原始需求或 Prompt；可选填补充背景。点击“生成可复制指令”，核对预览，再点击“复制指令”。若浏览器不允许自动复制，可选中输出并手动复制。
4. 把复制的**完整指令**粘贴到你自己的 AI 工具中，由该工具生成最终答案。网页不会替你发送。

切换优化师或修改输入后，旧结果会清除；输入内容保留在当前页面，方便重新生成。

## 本地与隐私边界

本项目只有本地 HTML、CSS 和 JavaScript，无构建步骤、第三方依赖、远程字体、API Key、网络请求或统计埋点。页面代码不将输入写入浏览器存储，也不自动上传；但浏览器可能恢复表单内容，点击复制后文本还会进入系统剪贴板。粘贴到外部 AI 工具后，内容将受该工具的隐私政策约束。敏感内容请先脱敏。
